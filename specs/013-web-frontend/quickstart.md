# Quickstart

Instalar dependencias con npm ci. Compilar con npm run build:web y npm run build:api. Configurar BOCHA_BACKUP_KEY y BOCHA_PUBLIC_ORIGIN; crear jefe mediante la CLI privada; iniciar npm run start:api. La aplicación queda en el origen configurado.

Desarrollo con Vite: BOCHA_PUBLIC_ORIGIN=http://localhost:5173 para la API y npm run dev:web. El proxy conserva Host/Origin. Pruebas: npm run check y npm run test:web. Ver [guía web](../../docs/frontend-web.md).
