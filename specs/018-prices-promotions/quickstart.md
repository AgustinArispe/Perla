# Quickstart de validación

1. Activar Promociones desde Configuración.
2. Seleccionar productos y simular un aumento; confirmar que el preview muestra antes/después.
3. Crear una promoción de cada plantilla y revisar el ejemplo.
4. Escanear productos alcanzados; comprobar etiqueta, ahorro y total.
5. Pausar la promoción con un carrito abierto; al cobrar debe pedir revisar el total.
6. Confirmar y consultar Histórico; el nombre y ahorro permanecen aunque cambie la promoción.
7. Ejecutar `npm run check` y `npm run test:web`.
