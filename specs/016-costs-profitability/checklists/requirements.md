# Checklist de requisitos

- [x] Costo promedio ponderado exacto para unidades y kilos.
- [x] Referencia manual sólo para productos sin seguimiento de stock.
- [x] Fotografía inmutable dentro de cada renglón de venta.
- [x] Compra, costo y stock confirmados en una única transacción.
- [x] Anulación segura y bloqueo cuando existe un costo posterior.
- [x] Cobertura explícita; los faltantes no se computan como cero.
- [x] Desglose mensual por producto y categoría.
- [x] Permisos de vendedor, supervisor, jefe y administrador.
- [x] Función modular desactivable sin borrar historial.
- [x] Dashboard, detalle de venta, ayuda y reporte imprimible.
- [x] Backup y restauración de todos los datos de costo.
- [x] Verificación automatizada y recorrido real en navegador.
