# Quickstart de validación

1. Activar Notificaciones desde Configuración.
2. Dejar un producto por debajo del mínimo y comprobar la campana.
3. Marcar el aviso como leído, modificar nuevamente la cantidad y comprobar que vuelve a quedar pendiente.
4. Ingresar como supervisor y confirmar que no aparecen diferencias de caja ni comparativos.
5. En Resumen mensual elegir Hoy, Semana, Mes y un rango; revisar fechas e importes anteriores.
6. Validar escritorio, 360 px, `npm run check` y `npm run test:web`.
