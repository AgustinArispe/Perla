# Prueba local — cinco meses

URL: http://localhost:3087/

Inicio: `npm run demo:market:start`. La base vive en `.data/five-month-local/pos.sqlite`; la base de prueba anterior se conserva aparte.

Datos ficticios: 4.000 artículos, 13.813 ventas, 769 compras, 80 clientes, 10 proveedores y cuatro ubicaciones. Dos cajas abiertas y cuatro perfiles.

Acceso de demostración: jefe / MareaDemo2026!; caja1, caja2 y fiambreria / CajaDemo2026!.

La interfaz conserva la marca Perla Negra. Búsqueda con flechas/Enter, clientes desde carrito y venta a cuenta, proveedores en navegación, configuración por pestañas, dashboard sin totales duplicados y stock por ubicación con validación de traslado.

La capacidad de backup permite la base de simulación de 230 MB. No se cambiaron datos de la base local anterior.
