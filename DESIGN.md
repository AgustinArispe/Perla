# Sistema visual

Interfaz para operar, extendiendo el sistema existente. Blanco predominante, neutros cálidos, verde para acciones y selección. Rojo para errores y operaciones destructivas; ámbar para avisos de stock.

Segoe UI/system-ui. Valores tabulares, importes destacados, controles de caja grandes. Sin animación en escaneo ni acciones de teclado. Navegación estable por módulos y permisos. Tablas legibles y formularios con etiquetas visibles. Sin leyendas redundantes ni etiquetas decorativas sobre títulos.

Escritorio: navegación lateral y espacio amplio para operar. Pantallas pequeñas: navegación horizontal y tablas desplazables. Diálogos accesibles para operaciones que necesitan foco protegido.
